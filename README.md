\# 🚆 AI Railway Block Planner



AI-powered automatic block planning to maximize asset availability for train operations on Indian Railways.



\## 🎯 Project Overview



The AI Railway Block Planner automatically recommends maintenance block windows for railway assets by considering:



\- Maintenance task severity

\- Asset criticality

\- Maintenance urgency

\- Task duration

\- Asset location / operational zone

\- Available block windows

\- Scheduled train movements

\- Block capacity



The system generates an explainable maintenance plan that helps railway planners use available maintenance blocks efficiently while avoiding train-operation conflicts.
